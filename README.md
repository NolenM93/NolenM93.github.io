# Nolen Millington

Personal developer portfolio for GitHub Pages.

Live URL after Pages is serving `main` from the repository root: [https://nolenm93.github.io](https://nolenm93.github.io)

This is a **user site** (`NolenM93.github.io`). Files in the root of `main` are the site. There is no `/docs` folder and no Jekyll build (see `.nojekyll`).

## Local

```bash
python3 -m http.server 4173
```

Open http://localhost:4173

## GitHub Pages

If the site 404s after this branch is merged to `main`, enable Pages in the repository settings:

1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main`
4. Folder: `/ (root)`
