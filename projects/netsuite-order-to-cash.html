NetSuite Order-to-Cash Toolkit

A NetSuite SuiteScript 2.1 and SDF project that implements common order-to-cash customizations for a fictional small wholesale distributor, Acme Wholesale Distributors.

SuiteScript 2.1SDFJestNot a live deployment
GitHub repoBack to work

Built and unit-tested against SuiteCloud mocks. Not deployed to a live NetSuite account. Acme Wholesale Distributors is a fictional business used for the scenario.

What it covers

User Event scripts for server-side validation, Client Scripts for form interactivity, a Scheduled Script for overdue invoice reminders, Map/Reduce for AR aging, a Suitelet collections dashboard, and a RESTlet for order status and lead creation.

Shared utility libraries keep the scripts testable. The repo documents governance checks, XSS escaping for Suitelet output, and configurable script parameters.
