Personal project

Excelerated

A guided, experimental goal planning and execution coach. A person describes a desired future. Excelerated collects only the decision-critical facts, keeps an evidence ledger, runs deterministic gates, and compiles a plan from a small reviewed action catalog.

Next.jsTypeScriptPostgreSQLVitest

This first slice is a working prototype for two low-risk archetypes: beginner Spanish and basic home cooking. It is not a validated scoring system and it does not give medical, financial, or legal advice.

The model proposes typed facts with source quotes. Code decides. The model cannot set verified, consent, gate-release, or completion state.
